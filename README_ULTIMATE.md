# 美易在线答疑系统 - 终极版

## 🌟 系统特点

### 核心功能
1. **智能问答**：基于知识库自动回答合规和报销相关问题
2. **多答案显示**：不再只显示一个答案，而是显示所有相关的答案
3. **模糊搜索**：支持同义词扩展和智能匹配
4. **分类浏览**：按类别查看和管理常见问题
5. **智能推荐**：根据关键词推荐相关问题
6. **统计分析**：实时显示搜索统计和历史记录

### 技术架构
- **前端框架**：Streamlit
- **文档解析**：python-docx
- **搜索算法**：增强的模糊匹配算法
- **分类系统**：自动问答分类
- **高亮显示**：HTML关键词高亮

## 🎯 使用指南

### 1. 智能问答
- 在输入框中输入您的问题
- 系统会自动搜索并显示所有相关答案
- 答案按相似度排序，分为高相关和相关参考两组

### 2. 分类浏览
- 点击"分类浏览"标签
- 选择特定分类查看相关问题
- 可以快速点击问题进行提问

### 3. 统计信息
- 查看知识库统计信息
- 查看热门搜索词
- 查看对话历史统计

## 🔍 搜索技巧

### 支持的搜索方式
1. **完全匹配**：输入完整问题获得最精准结果
2. **关键词搜索**：输入问题中的关键词
3. **同义词搜索**：
   - "重置密码" = "找回密码" = "修改密码"
   - "邮箱" = "电子邮箱" = "email"
   - "收不到" = "未收到" = "没收到"

### 搜索建议
- 使用2个以上关键词提高准确性
- 尝试不同的表达方式
- 如果找不到答案，尝试简化问题
